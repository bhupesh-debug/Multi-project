# Asymptote Systematic Signal — Regime-Aware Signal Engine

**A systematic-signal, KPI-dashboard and scenario-analysis project built for the
Business Analyst Intern role at Asymptote Capital (New York, NY).**

> ⚠️ **ALL DATA IS SYNTHETIC.** Prices, regimes, business KPIs and backtest
> results are generated by code (seed 42). Tickers are prefixed `SYN_` so
> nothing can be mistaken for live prices. This is a demonstration of the
> *pipeline* — data work, modelling, backtesting, dashboards, scenario
> analysis — not a trading strategy and not evidence of a real edge.

## What it does

Given trailing price features for four synthetic asset proxies
(equity-like, bond-like, commodity-like, FX/carry-like), the project:

1. **Predicts** whether each asset will be higher in 20 trading days
   (binary signal) and which market regime comes next (bull/range/bear).
2. **Backtests** the signal as a daily long/flat/short strategy against a
   momentum-rule baseline and buy-and-hold, with transaction costs.
3. **Reports KPIs** in an Excel dashboard — strategy metrics plus synthetic
   firm KPIs (AUM, revenue, costs, operating margin, headcount).
4. **Stress-tests** the strategy with bull/base/bear scenarios and a
   2,000-path Monte Carlo (block bootstrap).

## Results (test period 2024–2025, chronological split — real run output)

| Model | Accuracy | ROC-AUC | Precision | Recall | F1 |
|---|---|---|---|---|---|
| Logistic regression | 0.501 | 0.560 | 0.478 | 0.789 | **0.596** |
| Random forest | 0.544 | 0.558 | 0.509 | 0.594 | 0.548 |
| Hist. gradient boosting | 0.528 | 0.553 | 0.495 | 0.575 | 0.532 |
| Momentum rule (baseline) | 0.514 | — | 0.477 | 0.436 | 0.456 |

3-class regime classifier accuracy: **0.460** (chance ≈ 0.33).

| Backtest (502 days) | Total return | CAGR | Sharpe | Max drawdown |
|---|---|---|---|---|
| **ML signal** | **+7.7%** | **3.8%** | **0.54** | **−9.3%** |
| Momentum rule | +3.6% | 1.8% | 0.24 | −9.6% |
| Buy-and-hold | −15.1% | −7.9% | −0.83 | −22.4% |

Honest read: the models are only modestly predictive (AUC ≈ 0.56, accuracy
≈ 0.50–0.54). The backtest edge comes mostly from **avoiding the test-period
bear drawdown** (buy-and-hold lost 15%) via flat/short positioning, not from
precise return forecasts. The class balance itself shifted between train
(53% up-days) and test (47% up-days). On synthetic data that embeds momentum
and regime persistence, a model that learns those patterns is *expected* to
beat a rule — that proves the pipeline works, not that the signal is real.

Scenario engine (ML-signal strategy, 1-year): bear **−10.5%** expected return,
base **+4.1%**, bull **+21.1%**. Monte Carlo (2,000 paths): median terminal
wealth of $1 is **$1.03** (p5 $0.94, p95 $1.14); 29% chance of ending below
$1; 1.4% chance of a >10% drawdown.

Top features (random forest): 20-day volatility (0.13), vol ratio (0.11),
distance from 252-day high (0.11), 60-day return (0.10), MA ratio (0.09).

## How to run

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
.venv/bin/python -m unittest discover -s tests -v
```

`run.py` regenerates everything: synthetic data, features, trained models,
backtest, scenarios, 7 charts, the Excel dashboard and the model report.
Python 3.12+ required.

## Limitations (read before citing this anywhere)

- **Synthetic data only.** No real prices, no real Asymptote data, no live
  market claim. The generator embeds the very patterns the model learns.
- **Weak signal.** AUC ≈ 0.56; accuracy barely above chance. Do not present
  the backtest as a viable strategy.
- **No costs beyond 5 bps/position-change.** No slippage, borrow costs,
  capacity limits, or corporate-action handling.
- **Single chronological split**, not purged walk-forward validation.
- **What real data would need:** survivorship-bias-free prices, point-in-time
  fundamentals, proper transaction-cost modelling, purged walk-forward
  validation, and independent backtest review.
- **Eligibility flag (not a model issue):** the JD asks for candidates
  *currently pursuing* a Bachelor's/Master's; the candidate completed his
  M.S. in Dec 2025 — confirm eligibility with the recruiter before applying.
  Apply by Nov 18, 2026 at 10:59 AM per the posting.
