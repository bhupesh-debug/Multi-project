# Data dictionary — synthetic datasets

All files under `data/synthetic/` are **generated by code** (`src/data_pipeline.py`,
seed 42). No real market data, no real company data.

## synthetic_prices.csv — 1,827 rows (business days, 2019-01-01 to 2025-12-31)

| Column | Type | Meaning |
|---|---|---|
| date | date | Business day |
| SYN_EQ | float | Synthetic equity-like proxy price (start 100) |
| SYN_BD | float | Synthetic bond-like proxy price (start 100) |
| SYN_CMD | float | Synthetic commodity-like proxy price (start 100) |
| SYN_FX | float | Synthetic FX/carry-like proxy price (start 100) |
| regime | string | Hidden market regime that day: `bull` / `range` / `bear` (Markov chain) |
| source | string | Always `synthetic` |

Prices follow a regime-switching process: each regime gives each asset a
different annualised drift/volatility, plus a shared volatility-clustering
shock. Regimes are persistent by construction — that persistence is what
the model learns, which is exactly why backtest results here are a
pipeline check, not evidence of an edge.

## synthetic_business_kpis.csv — 84 rows (monthly, 2019-01 to 2025-12)

Fictional firm metrics for a systematic manager. Not Asymptote Capital.

| Column | Type | Meaning |
|---|---|---|
| month | string | YYYY-MM |
| aum_usd_m | float | Synthetic AUM, $m (driven by SYN_EQ returns + noisy net flows) |
| net_flows_usd_m | float | Synthetic net flows that month, $m |
| revenue_usd_m | float | Annualised revenue, $m (AUM × 45 bp fee) |
| costs_usd_m | float | Annualised costs, $m ($8m base + $0.30m per head) |
| headcount | int | Synthetic headcount |
| operating_margin_pct | float | (revenue − costs) / revenue × 100 |
| revenue_per_head_usd_k | float | Annualised revenue per employee, $k |
| source | string | Always `synthetic` |

## processed/model_frame.csv — 6,224 rows

One row per (date, asset). Trailing-only features (see `src/feature_engineering.py`
for definitions) plus forward targets: `target_up` (1 if the asset is higher
in 20 trading days), `target_regime` (bull/range/bear from the 20-day return),
`target_ret` (raw forward 20-day return). Rows needing a full 252-day trailing
window or a 20-day forward window are dropped, which is why the frame starts
in late 2019.
