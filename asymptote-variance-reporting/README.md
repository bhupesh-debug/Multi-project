# Asymptote Variance Reporting — Variance Analysis + Automated Management Reporting

**A variance-analysis, forecasting and automated-reporting engine built for the
Business Analyst (full-time) role at Asymptote Capital, New York, NY.**

> ⚠️ **ALL DATA IS SYNTHETIC.** AUM, fees, costs, returns and every variance in
> this project are generated by code (seed 42). Strategy names are prefixed
> `SYN_`. Nothing here is real Asymptote Capital data, real fund performance,
> or real market data. This project demonstrates the *pipeline* — variance
> decomposition, forecasting, anomaly flagging and automated reporting — not
> real firm performance.

## Why this project — and why it is NOT the sibling project

A sibling project was built for the Asymptote Business Analyst **Intern** role
(`~/workspace/ml-project-asymptote-systematic-signal/`): a regime-aware
**systematic signal engine** — it predicts 20-day asset returns, backtests a
long/flat/short strategy and stress-tests it with Monte Carlo. That is a
*trading-signal* project.

**This project is deliberately different, because this JD is different.**
The full-time Business Analyst JD is about *running the business*: variance
analysis, budgeting and forecasting, KPI tracking, management reporting and
automated reporting workflows. So this project:

| Sibling (intern role) | This project (full-time role) |
|---|---|
| Predicts asset returns | Explains **budget-vs-actual variances** |
| Backtests a trading strategy | Builds a **profit bridge** (budget → actual) |
| Regime classification | **Revenue decomposition**: AUM effect + fee-rate effect + performance-fee effect |
| Monte Carlo on strategy wealth | **3-month revenue/cost forecast** with 95% intervals |
| KPI dashboard as a side output | **Automated monthly reporting pack** (Markdown + Excel) as the core output |
| Anomaly = regime shift | Anomaly = **unusual variance month** (rules + Isolation Forest) |

No code, data or results are shared between the two projects.

## What it does

Given 24 months (Jan 2024–Dec 2025) of synthetic monthly data for four
synthetic strategies (Equity L/S, Global Macro, Credit RV, FX/Rates) plus
firm-level opex, one command produces the whole monthly management pack:

1. **Variance analysis** — revenue, cost and operating-profit variance vs
   budget *and* vs rolling forecast, at firm and strategy level, with a
   materiality rule (|var| ≥ 10% **and** ≥ $50k).
2. **Exact variance decomposition** — every strategy-month's revenue variance
   splits into AUM effect + fee-rate effect + performance-fee effect, and the
   three effects sum exactly to the total (unit-tested on all 96 rows).
3. **Profit bridge (waterfall)** — budget operating profit → revenue variance
   → cost variance → actual operating profit; ties out exactly every month.
4. **Forecasting** — seasonal naive vs Holt linear trend vs Ridge (trend +
   month dummies), compared on a 6-month time-based hold-out; the winner
   forecasts revenue and cost 3 months ahead with 95% prediction intervals.
5. **Anomaly detection** — material-variance rules (firm + cost-line level)
   combined with an Isolation Forest on variance features; flags ANOMALY /
   WATCH / Normal with an explainable reason.
6. **Automated reporting** — a Markdown variance report, a 7-sheet Excel
   management workbook, 4 charts, and a model report. Re-run for any month:
   `python run.py --month 2025-03`.

## How to run

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run.py                  # December 2025 report (latest month)
python run.py --month 2025-03  # any month in Jan 2024 – Dec 2025
python -m unittest discover -s tests -v   # 16 tests
```

## Honest limitations (read before citing this project)

- **Synthetic data only.** Variances, shocks and forecast accuracy demonstrate
  the pipeline, not real forecasting skill or real firm performance. No result
  here should be quoted as evidence about Asymptote Capital or any real fund.
- **Performance fees are lumpy by design.** The fee is 20% of monthly returns
  above a 1% hurdle, so a single strong strategy-month can swing firm revenue
  ±50–100% vs budget (e.g. Apr 2024 +95%, Nov 2024 +118%). That lumpiness is
  realistic for a performance-fee business — and it is exactly why the
  decomposition (AUM vs rate vs performance-fee effect) matters — but it also
  means monthly revenue variance is a noisy signal and the forecast intervals
  are wide (revenue 95% interval ≈ ±$1.06m on a ~$4.2m forecast).
- **Anomaly detection missed one injected shock** (Nov 2024, see table above)
  and flags two unexplained months (May 2024, Dec 2024) that are noise, not
  injected events. 24 monthly points is a small sample for unsupervised
  detection; every flag is a prompt for human review.
- **Forecast models are statistical baselines**, not a production forecasting
  system: no macro drivers, no AUM flow model, no high-water-mark logic, and
  the hold-out is only 6 months.
- **No real-firm knowledge is embedded.** Budget phasing, fee rates and cost
  lines are plausible assumptions, not Asymptote's actuals.
